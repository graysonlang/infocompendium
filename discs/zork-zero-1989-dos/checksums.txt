# Zork Zero, MS-DOS retail release (1989) - floppy image checksums
#
# Imaged 2026-09-12 from the 3.5" diskettes of an original dual-media retail
# box (two 720K 3.5" diskettes plus three 5.25" diskettes) via a USB 3.5"
# floppy drive. macOS does not grant the console user the USB floppy's device
# node (unlike optical drives), so the capture goes through hdiutil:
#
#   hdiutil create -srcdevice /dev/diskN -format UDRO disk.dmg
#   hdiutil convert disk.dmg -format UDTO -o disk   # then rename .cdr to .img
#
# The .img files are raw 720K sector images (1440 x 512).
#
# No Redump entries exist for Infocom floppies; these hashes stand as the
# reference for this pressing.
